# 🎴 Memory FlipCard Game

¡Bienvenido al **Memory FlipCard Game**! Un juego de memoria clásico desarrollado con tecnologías web fundamentales. El objetivo es encontrar todas las parejas de iconos de redes sociales antes de que se agote el tiempo.

## 🚀 Características
- **Sistema de Puntuación:** Contador de giros (flips) en tiempo real.
- **Temporizador:** Tienes 20 segundos para completar el desafío.
- **Barajado Aleatorio:** Las cartas cambian de posición en cada partida.
- **Diseño Responsivo:** Adaptado para dispositivos móviles y escritorio.
- **Animaciones Suaves:** Efectos de giro 3D y animación de error (shake).

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica del juego.
- **CSS3:** Estilos avanzados, Flexbox, animaciones y transformaciones 3D.
- **JavaScript (ES6):** Lógica del juego, manejo del DOM y temporizadores.
- **Boxicons:** Biblioteca de iconos vectoriales para las redes sociales.

🎮 Cómo Jugar
Abre el archivo index.html en tu navegador favorito.

-Haz clic en cualquier carta para revelarla.

-Selecciona una segunda carta:

-Si los iconos coinciden, las cartas permanecerán visibles.

-Si no coinciden, se agitarán y volverán a taparse tras un breve momento.

-Encuentra las 6 parejas antes de que el contador llegue a 0.

-Usa el botón Reiniciar para barajar las cartas y comenzar de nuevo en cualquier momento.
